Criando seu primeiro jogo no navegador

Conteúdo gerado por IA para demonstração.

Com apenas HTML, CSS e JavaScript, você pode fazer um jogo onde o usuário clica em um botão que se move. Isso ensina eventos, manipulação do DOM e lógica básica.

<button id="catchMe">Clique aqui!</button>
<script>
  const btn = document.getElementById('catchMe');
  btn.addEventListener('mouseenter', () => {
    const x = Math.random() * (window.innerWidth - 100);
    const y = Math.random() * (window.innerHeight - 100);
    btn.style.position = 'absolute';
    btn.style.left = x + 'px';
    btn.style.top = y + 'px';
  });
  btn.addEventListener('click', () => alert('Você ganhou!'));
</script>
